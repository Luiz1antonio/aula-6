# Mercado Fácil

Site demonstrativo de mercado online com cinco telas:
1. Início
2. Cadastro / Login
3. Sistema principal (catálogo e busca de produtos)
4. Carrinho e finalização
5. Meus pedidos

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).

## Arquivos
- `index.html`: estrutura e as cinco telas.
- `style.css`: cores, layout e responsividade.
- `script.js`: busca, categorias, carrinho, cadastro/login demonstrativo e pedidos.

Observação: é um protótipo front-end. Cadastro, login e pedidos não usam servidor ou banco de dados e não fazem cobranças reais.
